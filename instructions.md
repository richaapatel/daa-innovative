# Quick instructions

1. Open a terminal in this folder.
2. Install the one dependency:

   ```powershell
   python -m pip install -r requirements.txt
   ```

3. Start the app:

   ```powershell
   streamlit run server.py
   ```

4. Enter four rows of four letters and click **Run benchmark**.

The results table compares runtime and search statistics. Expand **Words and
paths** to see the coordinates for the words found.
